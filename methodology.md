# 📋 Evaluation Methodology

## Pairwise Response Comparison — Finance Domain

### Overview
Each evaluation task presented two AI-generated responses (Response A and Response B) to a finance or legal prompt. The evaluator's role was to determine which response better served a professional financial context.

---

## Evaluation Process

### Step 1 — Independent Assessment
Read each response independently without cross-referencing, assessing:
- Is the financial information accurate?
- Is the reasoning logically sound?
- Are regulatory references correct?
- Is the response complete and actionable?

### Step 2 — Comparative Analysis
Compare both responses across key dimensions:

| Dimension | Questions Asked |
|---|---|
| Accuracy | Which response contains fewer factual errors? |
| Depth | Which provides more meaningful analytical insight? |
| Compliance | Which better respects regulatory frameworks? |
| Clarity | Which communicates more clearly for a finance professional? |
| Completeness | Which addresses the full scope of the question? |

### Step 3 — Preference Selection
Select the superior response (A or B) or flag as a tie, with written justification explaining the key differentiating factors.

### Step 4 — Feedback Submission
Provide structured feedback identifying:
- Specific errors or weaknesses in the inferior response
- What made the superior response better
- Suggestions for improvement

---

## Common Error Patterns Identified

### Financial Calculation Errors
- Incorrect WACC computation (mixing nominal/real rates)
- Terminal value formula misapplication
- Working capital sign convention errors
- Currency/unit inconsistencies

### Regulatory Misstatements
- Incorrect EU directive references
- Outdated compliance thresholds
- Jurisdiction confusion (US GAAP vs IFRS)

### Reasoning Failures
- Circular logic in valuation arguments
- Confusing correlation with causation in market analysis
- Overly confident projections without uncertainty acknowledgment

### Hallucination Patterns
- Invented company financial data
- Non-existent regulatory provisions cited
- Fabricated market statistics

---

## Quality Standards Applied

All evaluations were benchmarked against:
- **CFA Institute** standards for investment analysis
- **IFRS/EU GAAP** financial reporting standards
- **EU regulatory frameworks** (MiFID II, EMIR, CRD)
- **Professional investment banking** communication norms
